### 为什么收录

ZYW 的最终报告 §15 用两套仪器对跑,结论与本仓一致、逐档吻合:

| H | 本仓(WFY, main.c, train=128) | ZYW(bhb_final.c, train=128) |
|---|---|---|
| 224 | 39.0% | 36.61% |
| 256 | 35.5% | 31.65% |
| 288 | 25.1% | 24.25% |
| 304 | 17.8% | 15.16% |

排序完全一致,差异可归因于训练强度与统计口径,非实验误差。两平台交集最优点 = **H=256**。

### ZYW 这套标定的 N2 参数(供参考)

`HISTORY_SIZE=256`、`--train-n=32`(1→32 提升 55%,之后饱和)、`THR=4`(dt 分布谷底 3~6 中点)。
主结果:MAIN 16.61% vs CTRL 0.065%(256×),CTRL 强碰撞在 20 万轮中为 0,异地对照 800 万次零命中。
