## 1. v2 攻击复现(L1-1 + L1-2H)—— 完成,已统一成稿

**一句话:原语成立 + 机制讲清 + 迁移判否,完整闭环。** 把 zyw 的背景调研与原语标定、wfy 的机制刻画与迁移判定合并为一份《攻击复现报告》。

**结论(五句话):**

1. 背景与场景(zyw 调研):v2 危害是"读任意内存";云上真实威胁面是"同一 VM 内共享库",跨租户被 CSV2 + 无 SMT 挡死。
2. 实验一:同进程 EL0、缓解全开下原语成立 —— MAIN 16.61% vs CTRL 0.065%(256 倍),CTRL 在 20 万轮中无一次强碰撞。
3. BTI 在推测执行层同样被硬件强制,把乱跳落点压回合法函数入口(四臂矩阵 100/0/100/100)。
4. 同进程内对库自己拥有的间接调用做历史训练带偏可行(59.0%,95% CI 57.6–61.2),但历史从库外跨边界喂就塌到 ~1% —— 这是迁移的硬门槛。
5. "搬进 OpenSSL/mbedTLS 偷真钥匙"在本平台这些库上定量不成立:11 库 ~8400 站点,"目标可控 ∩ 助跑够长" = 0。

**边界(必须一起说):** 结论绑今天这批二进制 + 这颗 N2 核;只否掉"BHB 带偏跳转"一条路,不覆盖 Spectre-v1 等其它瞬态通道;ASN1 的"无落点"是"未观测到"(本机无 PMU),但有 contig 机制 + 全库交集为 0 兜底。

**分工:** 背景调研 zyw;原语仪器与参数标定 zyw·wfy(配对循环与标定 zyw,POS/SELF 闸门与训练强度 wfy);机制刻画与迁移判定 wfy。

**作废记录(勿引用):** 21% / 44.8% / 48.2% 三个早期数,均因装置缺 SELF 闸门造成的假阳,已撤;点估计 58.8% 改为中位数 + 置信区间。

**交付:** 《倚天710_Spectrev2_攻击复现报告》PDF,12 页;评审 7 条意见(5.2 正文补数字、图A4 删 192、图编号统一、分工补 wfy、9.1 补原语数字、TC-10 去 192、代码出处注)已全部闭环。

## 2. MDU 可测量性 / 跨进程可观测(L1-3)—— 启动,ruler 已过,信号未测

**任务:** 确认 710 上 MDU 是否可测量(Q-A,同进程),重点确认能否跨进程观测(Q-B)。参考 MDU 泄漏论文。

**今天的进展:**

- 交接简报成文(`claude/L1-3_MDU可测量性_交接简报.md`),供新对话无上下文接手。
- **ruler 自检 PASS**(测量地基):
  - 平台复核:Neoverse-N2 / 4 核 / Thread per core = 1(无 SMT)/ 3000 MHz 锁定。
  - 计时器绝对校准:cntfrq 50MHz → 20ns/tick;100ms 名义 vs 100.065ms 实测(偏 0.07%)。
  - 删-fence 主口径:hot 1.0 / cold 10.0 tick,ratio 10.00,两态分布不重叠(cold_p5 9.0 > hot_p95 2.0);BATCH=64 批量放大。判据 ratio≥2 + 不重叠,PASS。

**重要限定:ruler PASS ≠ MDU 可测。** ruler 只证明计时器能分开 cached(20ns)/flushed(200ns)这个大沟,是测量地板,不是 MDU 信号。MDU 的操作数相关信号是另一个、很可能小得多的量,尚未触及。

**结论状态:Q-A / Q-B 均未得出,不下任何 MDU 结论。** 下一步是 SELF 闸门(用已知信号自撞,过了才算可测)。

**阻塞项:需要 MDU 泄漏论文原文** —— MDU 的具体定义、信道类型、跨进程前提(是否依赖 SMT)均以论文为准,未到位前不预设、不预判。
