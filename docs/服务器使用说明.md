## 1. 操作手册

### 1.2 用户、目录与文件传输

**用户**：默认使用姓名首字母作为用户名，初始密码和用户名相同，可自行修改。（例如“杨东霖”的用户名为 `ydl`，用户家目录为 `/home/ydl`，初始密码为 `ydl`）。

**目录**：用户家目录下文件可以随意读写。此外，`/srv/lab/` 供 lab 组用户读写，可以用于共享文件。

**文件传输**：可以使用 `sftp` 等使用 SSH 协议的文件传输方案。

### 1.3 权限边界

简言之，为了便利性，所有用户都给了完全的 `sudo` 权限。但为了便于管理，避免破坏系统，希望大家自觉约束自己 `sudo` 的使用，非必要不 `sudo`，更不应 `sudo -i` 在 root shell 中工作。

**可以做**：

- 修改用户家目录下的任何文件
- 修改用户级配置
- 安装用户级软件包（如 `npm install` `cargo install` 等）
- 其它只影响本用户的行为

**可以做，但是提前说一声**：

- `sudo apt`
- 添加、关闭服务（`sudo systemctl`）
- 其它基本无害，但是可能影响其它用户使用的行为

**不应做**（如需联系管理员）：

- 修改系统级配置（例如 `/etc/`）
- 修改系统用户、用户组
- 重启、关机等
- 在未经他人同意的情况下，通过 `sudo` 访问他人用户家目录下的文件和目录
- `sudo -i` 在 root shell 下进行日常工作
- 其它修改系统的行为

### 1.4 开发环境

#### C

已安装 `gcc` `gdb` `clang-format` `clangd`

#### Python

高版本 Ubuntu 受 PEP 668 保护，禁止直接 `pip install`。不建议绕过保护。

如果需要安装 Python 包，可以给当前用户或项目建立专门的 venv 虚拟环境。同时我也在 `/opt/lab/venv` 放了一个所有用户可用的 Python 虚拟环境。

#### NodeJS

建议使用 `nvm`（默认用户级）。参见 <https://nodejs.org/en/download>

#### Java

已安装 `openjdk-21-jdk`。

如果确实需要其它版本的 jdk，直接 `sudo apt` 安装即可，并使用 `update-alternatives` 切换。

### 1.5 网络与防火墙

目前防火墙仅放行 `TCP 22` 和 `ICMP-IPv4` 两类入站流量，其余入站流量会被阿里云安全组阻止。

如果需要部署服务，联系管理员以放行对应端口。

### 1.6 硬盘与备份

**硬盘**：硬盘不大。养成习惯每次用之前 `df -h` 看一眼，硬盘快满了及时报告。

**备份**：服务器已开启阿里云免费赠送的云硬盘备份服务。任何文件丢失及时反馈。但更建议大家**平时主动备份各自文件到本地**。



## 2. 初次使用

### 2.1 用户信息

默认使用姓名首字母作为用户名，初始密码和用户名相同，可自行修改。（例如“杨东霖”的用户名为 `ydl`，用户家目录为 `/home/ydl`，初始密码为 `ydl`）。

仅允许公钥连接。初次使用需用户本地生成密钥对后发给管理员。

### 2.2 生成密钥

在自己电脑上执行：

```bash
ssh-keygen -t ed25519 -C "<some_comments>"
```

`<some_comments>` 是密钥对的注释，自己填。建议填写能标识自己身份的，例如姓名首字母。

执行后会提示保存路径，默认是：

- 私钥：`~/.ssh/id_ed25519`
- 公钥：`~/.ssh/id_ed25519.pub`

其中 `xxx.pub` 为公钥，**发给管理员**。

### 2.3 登录

**在管理员确认用户添加完毕后**，登录：

```bash
ssh <user_name>@8.137.179.142 -i <private_key_file>
```

其中：

- `<user_name>`：用户名，默认为姓名首字母（例如“杨东霖”的用户名为`ydl`）
- `<private_key_file>`：和公钥一起生成的私钥文件，也就是公钥文件名去掉 `.pub` 后缀后的文件（例如公钥为 `~/.ssh/id_ed25519.pub`，则私钥文件为 `~/.ssh/id_ed25519`）

### 2.4 验证

首次登录执行：

```bash
id
sudo -v
```

预期：

- `id`：`groups` 中能看到 `lab` 和 `sudo` 组（典型如 `groups=1003(ydl),27(sudo),100(users),1001(lab)`）
- `sudo -v`：提示输入密码，输入后没有报错
